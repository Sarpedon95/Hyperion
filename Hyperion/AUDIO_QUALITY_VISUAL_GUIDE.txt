BADGE APPEARANCE:
─────────────────

Location: Top-right of Now Playing view (next to album name)

Normal State:
┌──────────────────────┐
│ NOW PLAYING   🟢 Lossless ▶ │
│ Album Name                  │
└──────────────────────┘

Color Codes:
  🟢 Green (Lossless)   — No degradation, pristine quality
  🟡 Amber (Converted)  — Some conversion but generally good
  🔴 Red (Limited)      — Wireless or lossy device
  ⚪ Gray (Unknown)     — Can't determine quality

Animation:
  Lossless playback shows pulsing ring animation on the green dot

Icons & Meanings:
  🎵 Source        — Input file format
  🌐 Streaming     — Server/source type
  ▶  Decode        — Decoding method
  〰  Bit Depth     — Bit resolution
  〰  Sample Rate   — Sampling frequency
  🔊 Volume        — Current volume level
  🎧 Output        — Audio device type
  ✓  Verification  — End-to-end quality check

REAL-WORLD EXAMPLES:
────────────────────

SCENARIO 1: LOSSLESS PLAYBACK
────────────────────────────

User plays FLAC album, wired headphones, full volume.

Badge: 🟢 Lossless (pulsing animation)

Signal Path:
  ✓ Source         FLAC
  ✓ Streaming      Lyrion Server
  ✓ Decode         Lossless decode
  ✓ Bit Depth      24-bit
  ✓ Sample Rate    48.0 kHz (no conversion)
  ✓ Volume         Full scale (100%)
  ✓ Output         Headphones
  ✓ Verification   Bit-perfect end-to-end


SCENARIO 2: LOSSY COMPRESSED
──────────────────────────────

User plays MP3 file on same setup.

Badge: 🟡 Converted (amber)

Signal Path:
  ⚠ Source         MP3
  ✓ Streaming      Lyrion Server
  ⚠ Decode         Lossy decode
  ✓ Bit Depth      16-bit
  ✓ Sample Rate    44.1 kHz
  ✓ Volume         Full scale (100%)
  ✓ Output         Headphones
  ✗ Verification   No (lossy source)


SCENARIO 3: WIRELESS DEVICE
─────────────────────────────

User connects Bluetooth speaker, plays FLAC.

Badge: 🔴 Limited (red)

Signal Path:
  ✓ Source         FLAC
  ✓ Streaming      Lyrion Server
  ✓ Decode         Lossless decode
  ✓ Bit Depth      24-bit
  ✓ Sample Rate    48.0 kHz
  ✓ Volume         Full scale
  ✗ Output         Bluetooth (lossy codecs)
  ✗ Verification   No (Bluetooth is lossy)


SCENARIO 4: VOLUME ADJUSTMENT
───────────────────────────────

User lowers volume to 40%, everything else same.

Badge: 🟡 Converted (amber) — quality drops due to low volume

Signal Path:
  ✓ Source         FLAC
  ✓ Streaming      Lyrion Server
  ✓ Decode         Lossless decode
  ✓ Bit Depth      24-bit
  ✓ Sample Rate    48.0 kHz
  ⚠ Volume         40% (reduced headroom)
  ✓ Output         Headphones
  ⚠ Verification   Reduced headroom

ANIMATION DETAILS:
────────────────

Pulsing Ring (Lossless):
  - Outer ring grows to 1.2× scale
  - Opacity fades from 0.6 to 0
  - Duration: 1.5 seconds
  - Repeats infinitely
  - Only shown for Lossless status

Transition:
  - Badge updates smoothly when route/track/volume changes
  - Modal reflects live state when opened
  - No delay between change and display update


INTERACTION FLOW:
──────────────────

User Journey:

1. User taps quality badge
   ↓
2. Modal animates up with current signal path
   ↓
3. User reads 8-step signal path
   ↓
4. User unplugs headphones / connects Bluetooth
   ↓
5. Modal updates in real-time to show new route
   ↓
6. User sees "Output: Bluetooth" with 🔴 Limited status
   ↓
7. User taps X to close modal
   ↓
8. Back to Now Playing, badge now shows 🔴 Limited
