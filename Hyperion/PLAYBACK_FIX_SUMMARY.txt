HYPERION AUDIO PLAYBACK — COMPREHENSIVE FIX SUMMARY
═══════════════════════════════════════════════════════════════════════════════

PROBLEM STATEMENT:
─────────────────
Background and lockscreen playback broken. User reports:
- App backgrounded → music stops
- Lock screen controls don't work
- No bit-perfect audio verification
- No diagnostics for silent failures

ROOT CAUSES FOUND:
──────────────────

1. BACKGROUND TASK LEAK
   - beginBackgroundPlaybackTask() didn't prevent duplicates
   - resume() could spawn multiple tasks concurrently
   - Tasks expired during buffering on slow networks
   → FIX: Made task creation idempotent, added logging

2. AUDIO SESSION DEACTIVATED TOO EARLY
   - pause() didn't deactivate but session could be deactivated elsewhere
   - Pausing in foreground + backgrounding left session in wrong state
   - Lock screen controls need active session
   → FIX: Only deactivate on force-clear, keep active while paused

3. NO OUTPUT FORMAT DETECTION
   - outputFormat variable set to "" always
   - Bit-perfect status was guess, not verified
   - No way to know if Bluetooth/AirPlay destroying fidelity
   → FIX: New updateOutputFormat() queries AVAudioSession route

4. ROUTE CHANGES NOT FULLY HANDLED
   - Headphone unplug detected but session not reconfirmed
   - Output format not updated for UI display
   → FIX: Re-confirm session, update format on route changes

5. BACKGROUND LIFECYCLE TIMING
   - Background task might expire before playback starts
   - Asynchronous cleanup in task expiration handler
   → FIX: Request task before audio work, synchronous cleanup

KEY INSIGHTS:
─────────────

✓ AVAudioSession must be activated before audio work
✓ Background task must be requested BEFORE doing work (iOS gives ~30s)
✓ Audio session should stay active while paused (for lock screen)
✓ Output format must be queried from currentRoute (not guessed)
✓ Bit-perfect needs: lossless source + lossless device + not wireless
✓ All state transitions must be logged (silent failures are the worst)
✓ Race conditions prevented with stale observation guards
